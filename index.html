Hermes Assistant

Hermes is a private, single-user assistant run by its owner on their own computer. It is not offered to the public.

Privacy policy

When its owner authorizes it, Hermes uses Google APIs (Gmail, Google Calendar, Google Tasks) to read and organize the owner's own data for the owner.

  • Data is used only to provide the assistant's features to the owner.
  • Data is not sold, shared with third parties, or used for advertising.
  • OAuth tokens are stored only on the owner's computer. Revoke access at any time at myaccount.google.com/permissions.

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
